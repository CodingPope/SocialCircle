## 📝 Documentation Standards

### Feature Documentation Should Include:

1. **Overview** - What the feature does
2. **Implementation** - Files changed, how it works
3. **User Experience** - What users see/do
4. **Technical Details** - Code patterns, APIs used
5. **Testing** - How to verify it works
6. **Known Issues** - Current limitations

### File Naming:

- `FEATURE_NAME.md` - Feature documentation
- `COMPONENT_NAME_FIX.md` - Specific bug fixes (temp, delete after)
- `ANALYSIS_TOPIC.md` - Investigation docs (temp, delete after)
